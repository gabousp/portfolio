## O problema

O processo de criação e gerenciamento de propostas comerciais
possuía tarefas manuais que poderiam ser automatizadas.

## A solução

Desenvolvi um sistema em Microsoft Access e VBA para estruturar
o processo de criação, gerenciamento e geração das propostas.

## Tecnologias

- Microsoft Access
- VBA
- SQL
- Relational Database

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Gerenciamento de propostas
- Validação de CPF/CNPJ
- Integração com APIs
- Geração de documentos
- Controle de acesso

## O que aprendi

- Modelagem relacional
