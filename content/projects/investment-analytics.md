## O problema

Acompanhar diferentes tipos de investimentos exige consolidar
dados de diferentes fontes e realizar cálculos específicos para
cada produto.

## A solução

Desenvolvi uma aplicação em Python para armazenar dados históricos,
processar informações de mercado e calcular a evolução das aplicações.

## Tecnologias

- Python
- Pandas
- SQLite
- NumPy
- Matplotlib
- APIs

## Arquitetura

```text
Fontes de dados
      ↓
    Python
      ↓
Tratamento dos dados
      ↓
    SQLite
      ↓
Cálculos e análises
      ↓
Visualizações
```

## O que aprendi

- Tratamento de séries temporais
- Integração com fontes externas
- Modelagem de banco de dados
- Cálculos financeiros
- Validação dos resultados
